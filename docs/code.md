# Разбор кода

Во всех шести программах один и тот же скелет: **разбить работу на куски, запустить их
выбранным способом, замерить время.** Отличается только «двигатель».

---

## Общий фундамент (Задача 1)

```python
N = 100_000_000
WORKERS = 4
```

`N` - до какого числа считаем. `WORKERS` - на сколько кусков делим и сколько работников
запускаем.

Функция `make_chunks(n, parts)` делит диапазон `1..n` на равные части и возвращает список пар
`(начало, конец)`. Хитрость в строке `end = n if i == parts - 1 else start + step - 1`:
последний кусок доводится ровно до `n`, чтобы из-за деления с остатком ни одно число не
потерялось.

Функция `calculate_sum(start, end)` в лоб складывает числа от `start` до `end`. Это чистое
вычисление - процессор занят постоянно.

---

## Ключевые конструкции по подходам

=== "threading"

    ```python
    threads = [threading.Thread(target=worker, args=(i, s, e))
               for i, (s, e) in enumerate(chunks)]
    for t in threads:
        t.start()
    for t in threads:
        t.join()
    ```

    - `Thread(target=..., args=...)` - создать поток: какую функцию и с какими аргументами;
    - `.start()` - запустить (все стартуют почти одновременно);
    - `.join()` - дождаться завершения всех перед замером времени.

=== "multiprocessing"

    ```python
    with Pool(WORKERS) as pool:
        parts = pool.starmap(calculate_sum, chunks)
    ```

    - `Pool(4)` - создать 4 процесса;
    - `starmap(функция, список_пар)` - раздать каждую пару своему процессу (пара
      распаковывается в два аргумента) и собрать результаты;
    - `with ... as ...` - гарантирует корректное закрытие процессов.

=== "async"

    ```python
    parts = await asyncio.gather(*[calc_async(s, e) for s, e in chunks])
    ```

    - `async def` - объявляет корутину;
    - `gather(*список)` - запускает все корутины разом (звёздочка распаковывает список в
      отдельные аргументы);
    - `await` - «дождись завершения»;
    - `asyncio.run(main())` - точка входа в асинхронный мир.

## База данных (Задача 2)

Файл `db.py` - общий «склад» для трёх парсеров: там лежат ссылки и функции базы.

```python
def save_page(url, title):
    conn = sqlite3.connect(DB, timeout=15)
    conn.execute("INSERT INTO pages (url, title) VALUES (?, ?)", (url, title))
    conn.commit()
    conn.close()
```

- вопросики `?` - это параметры: вместо них безопасно подставляются значения из `(url, title)`;
- `timeout=15` - если база занята другим потоком/процессом, подождать, а не падать сразу;
- `conn.commit()` - без него изменения не сохранятся.

Разбор заголовка одинаков во всех парсерах:

```python
title = soup.title.string.strip() if soup.title and soup.title.string else "Без заголовка"
```

Берём текст из тега `<title>`, убираем пробелы по краям, а если заголовка нет - подставляем
заглушку, чтобы программа не упала.

## Скрипты сравнения

`compare_all.py` в каждой задаче импортирует функции `run` из трёх файлов, добавляет
эталонный последовательный прогон, собирает время в словарь и печатает таблицу с ускорением.

```python
times = {
    "последовательно": run_sequential(),
    "threading": run_threading(),
    "multiprocessing": run_multiprocessing(),
    "async": run_async(),
}
base = times["последовательно"]
for name, t in times.items():
    print("{:<18}{:>10.2f}{:>14.2f}".format(name, t, base / t))
```

`base / t` - во сколько раз подход быстрее эталона.

## Питоновские конструкции

!!! abstract "Что означают частые записи в коде"
    - **`if __name__ == "__main__":`** - код внутри выполняется только при прямом запуске
      файла, но не при импорте. Позволяет `compare_all.py` импортировать функции, не
      запуская их случайно. На Windows обязательно для `multiprocessing`.
    - **`[f(x) for x in items]`** - генератор списка: короткий способ построить список в одну
      строку.
    - **`f"время = {t:.2f} c"`** - f-строка: вставляет значение переменной, `:.2f` - округлить
      до 2 знаков.
    - **`enumerate(items)`** - даёт пары «номер + элемент».
    - **`*список`** в `gather(*список)` - распаковка списка в отдельные аргументы.
    - **`args=(u,)`** - кортеж из одного элемента (запятая обязательна).
    - **`//`** - деление нацело.
